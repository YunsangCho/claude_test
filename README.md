# 한국사 카드덱

한국사능력검정시험 대비 학습 앱. 결과물은 `dist/한국사-카드덱.html` 파일 하나다.
폰에 저장해서 열면 인터넷 없이 동작하고 진도는 브라우저에 저장된다.

## 빌드

```bash
python scripts/build.py
node   scripts/check.mjs
```

## 현재 규모

- 문항 3,487개 (고정 3,154 + 엔진 생성 333)
- 카드 1,496장, 전 항목 해설 있음
- 40강 전 범위, 중복 0

## 학습 방식 12가지

카드 넘기기, 객관식, OX, 사료 제시형, 빈칸 채우기, 비교 카드, 순서 배열,
틀린 것 찾기, ㄱㄴㄷㄹ 조합, 연표 시기 판별, 정체 추론, 그림 문제

## 기능

- 간격 반복: 자가 채점 결과에 따라 1, 3, 7, 16, 35일 뒤 재출제
- 오답 노트와 별표 카드
- 취약 강 자동 추천, 강별 진도 게이지
- 실전 모의고사 50문항 50분, 난이도 기본과 심화 분리
- 학습 통계, 시험 D-day, 글자 크기 조절

## 엔진

`data/structured/` 의 항목 하나에서 문제 여러 개가 만들어진다.
광개토대왕 항목 하나로 틀린 것 찾기, ㄱㄴㄷㄹ 조합, 정체 추론, 업적 맞히기가 나오고
풀 때마다 보기 조합이 달라진다. 항목을 늘리면 문항이 곱으로 늘어난다.

작업 지침은 `CLAUDE.md` 참고.
